# 《侠客行》地图悬停路线预览

适用范围为实际游戏地图。悬停地图地块时，从角色当前位置显示行进路线，并在目标格旁显示预计行动点消耗。左键仍按现有规则发起移动。

## 显示规则

| 当前情况 | 地图表现 | 目标格旁提示 |
| --- | --- | --- |
| 有路线，行动点足够 | 绿色路线 | 消耗 N 点 |
| 有路线，行动点不足 | 红色路线 | 需 N 点，当前 M 点 |
| 地形阻挡或不存在路线 | 目标格用现有选格框标红 | 不可通行 |
| 已经过格可按现行规则免费瞬移 | 用绿色连接起终点表达直达 | 消耗 0 点 |
| 悬停角色所在格 | 无路线 | 当前位置，消耗 0 点 |

瞬移提示应能与逐格行走区分。若移动规则会在途中事件处强制停步，沿用现有停步判定，预览不可显示为可直接穿过事件并到达目标。完全无路时只标记目标格，保留红色反馈。

## 接入规则

- 在实际地图上绘制路线，复用当前地图、寻路、通行条件、迷雾、到访状态、瞬移规则和行动点计算。路径查询应能区分无路线与找到路线但行动点不足，行动点不足时仍可取得候选路线及完整消耗用于展示。
- 预览成本按实际计费口径计算。首次进入按地块配置计费，已揭示与已到访仍分别判断。行动点刚好够时显示绿色。
- 路线和消耗与左键执行所用的移动规则一致。左键仍由移动系统确认最新角色位置、通行条件、流程限制及行动点。悬停期间只读取地图状态，不移动、不扣点、不揭示地图、不触发事件，也不将地块标记为到访。
- 预览随当前悬停目标更新。离开地图、悬停到会拦截地图输入的 UI、开始移动或进入会锁住地图输入的流程时清除。地图恢复空闲后按新位置、行动点和地图状态刷新。已有悬停地块详情保留，消耗文字与详情避免互相遮挡。
- 路线由程序绘制，沿用现有选格框和文字样式。若地形对比不足，优先调整线宽和描边。本轮无需新增美术资源。先前示意预览仅供参考交互，地图外观与实际通行判定以工程现有地图为准。

## 验收

1. 在真实地图悬停可达目标，能看到绿色路线和所需行动点。左键执行后核对行进方向、停步结果和实际扣点。测试预算正好等于路线消耗的情况。
2. 悬停有路但超预算的目标，显示红色路线以及所需点数和当前点数。点击仍按现有移动限制处理。
3. 悬停完全无路的目标，目标框标红并提示不可通行。已到访可免费瞬移的目标显示 0 点。
4. 连续切换目标、移入 UI、离开地图或开始移动，旧路线和数字及时消失或更新。悬停不产生扣点、揭示、到访、移动或事件结算。
