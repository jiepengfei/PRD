# Step 02：第一场山贼展示、定位、战斗与任务推进

日期：2026-11-04  
状态：供用户评审；本次只整理需求，未上传仓库或通知远程执行。

## 1. 本次目标

在 Step 01 的主线接取与五日倒计时基础上，接通以下小段：

**接取主线 → 第一名山贼所在砖块直接翻面展示 → 点击主线聚焦山贼位置 → 到达触发战斗 → 胜利返回地图 → 同一主线更新为第二名山贼目标。**

本次只接第一场外围战及胜利后的任务目标更新，不接第二场战斗、首领、超时后果或结尾。

## 2. 第一名山贼的位置与展示

- 使用居民区外沿房屋附近的第一战锚点，配置实际逻辑地图 ID、砖块坐标、山贼展示及已有战斗配置。复用已有资源和地图事件能力。
- 主线成功接取后，直接揭示第一名山贼所在的那一块砖块，使用现有翻牌表现，展示地块内容和山贼标记；不是只把标记画在未揭示遮盖上。
- 只揭示目标砖块，不连带翻开路径、周围砖块或整个区域。目标格已揭示时不重复播放翻牌。
- 揭示不等于到访，不扣行动点、不移动玩家、不直接触发战斗。玩家之后首次走入该格，仍按原有到访和行动点规则处理。
- 目标位于可通行、可达的位置，不能放在房屋屋顶或山体内。接取前不主动提前暴露此任务目标，但普通探索已揭示的内容不重新盖回。
- 揭示结果接入已有地图探索状态；重进地图不重新盖住或重复翻牌。已战胜山贼时不能因刷新任务再生成敌人。

## 3. 点击主线聚焦

- 主线当前目标为第一名山贼时，点击地图上的主线任务条目，调用已有任务定位/地图镜头能力，将镜头平移聚焦到山贼所在砖块。
- 任务面板若已有定位按钮，也指向相同目标；不另造一套定位系统。不把任务分类 Tab 或所有面板操作都改成定位。
- 聚焦后使用已有选格框或目标高亮短暂提示目标位置；已有任务定位反馈可直接复用，不新增定位美术。
- 定位只移动镜头，不移动角色、不扣行动点、不启动寻路或战斗，也不额外揭示周围地图。
- 点击由任务 UI 消费，不穿透到地图。重复点击只重新聚焦同一目标，不叠加镜头动画；玩家手动拖动镜头可中断定位过渡。
- 首次接取任务时推送并揭示目标，不强制立即拉走镜头；玩家点击主线后再聚焦。
- 定位坐标来自任务当前目标的地图锚点，不在按钮代码中写死像素坐标。

## 4. 到达与战斗

- 主线处于第一战阶段且该山贼未被击败时，玩家实际到达该砖块，停止后续移动并触发第一场战斗。远距离寻路经过该格时同样检查，不能直接穿过。
- 查看详情、点击主线定位、揭示砖块及只看见山贼均不算进入战斗或战胜山贼。
- 调用工程已有独立战斗模块及配置，不重做战斗系统。进入后按既有规则锁住地图操作，避免重复启动战斗。
- 战斗胜利才提交清理、奖励和阶段推进。战败或撤退不清除山贼、不推进任务，沿用工程已有返回与重试规则。
- 战斗结果正常写回玩家状态，不能在回地图时意外恢复成战前模板或满血。奖励复用已有配置；缺失的敌群或奖励需列明，不引用不存在的 ID。

## 5. 胜利后的任务与地图

- 同一条“山贼来袭”主线保持进行中，当前目标更新为“前往山区，击退第二名山贼”。不能完成整条主线、发放主线最终奖励，或另接一条同名任务。
- 第一名山贼遭遇标记移除/切换为工程已有清理状态；该格保留揭示及实际到访记录，之后经过不再启动这场战斗。
- 任务列表、地图任务悬浮栏和定位引用同步刷新，不能仍将第一名山贼作为当前目标。
- 预留并绑定已有第二战锚点，更新后点击主线可聚焦第二目标位置；本轮不揭示第二目标、不生成其战斗入口、不接第二场战斗。第二目标格未揭示时，聚焦保持迷雾，不显示隐藏敌人。
- 五日倒计时沿用接取时的开始日与到期日，不因战斗胜利、目标更新或返回地图重新计时；普通战斗不额外推进游戏日期。
- 第一战胜利、奖励结算、事件完成和任务阶段更新作为一致结果提交，重复战果回调不得重复领奖或推进。
- 接好现有进度与存档接口；存档最终验收仍由用户负责，本轮不重复安排整套存档验收。

## 6. 完成标准

| 检查项 | 预期结果 |
| --- | --- |
| 主线接取 | 第一名山贼所在砖块直接翻面并展示山贼，周围未揭示格不受影响 |
| 揭示与到访分离 | 翻面不扣行动点、不移动、不触发战斗；首次进入仍按原规则处理 |
| 点击主线 | 镜头聚焦山贼砖块并有定位反馈，角色位置与行动点不变，无点击穿透 |
| 重复点击 | 无多个镜头动画竞争，无重复翻牌或重复生成山贼 |
| 到达遭遇 | 实际进入或寻路经过目标格即停止移动，只启动一次战斗 |
| 失败重试 | 不清敌、不发胜利奖励、不更新目标，能够按已有规则再次挑战 |
| 战斗胜利 | 地图恢复，第一战清理，同一主线更新为第二战目标，奖励仅结算一次 |
| 目标定位更新 | 更新后点击主线不再聚焦第一战，而是第二战锚点；不揭示第二目标 |
| 日期与进度 | 原期限保持，重进地图不会复活已完成山贼或倒退主线 |

交付实际运行截图或短视频，至少展示接取后翻面、点击主线定位、第一战胜利后的地图与任务目标，并说明修改配置、验证结果及未解决项。

## 7. 后续步骤

本步完成后，再单独安排第二名山贼的展示、触发、战斗和首领入口开放。主线整体规划不作为本次额外实施范围。
