## 2. 地图入口接入

- 继续使用第二战胜利时开放的同一首领入口及实际地图锚点，绑定正式地下城 ID，不新放重复入口。
- 第二战未胜利时不可进入；不能通过旧详情操作、直接交互或其他调用绕过条件。
- 入口开放后按既有地图交互方式打开地下城节点图。入口若有“开始挑战”操作，其结果是打开节点图，不能立即跳过节点图开战。
- 未探索的入口仍服从迷雾规则；任务定位只聚焦，不自动翻开区域。沿用 Step 03，不额外改探索规则。
- 地图与地下城 UI 按既有窗口/输入归属切换，不允许地图操作穿透。暂离时返回原地图安全落点，保留当前关卡进度。

## 3. 正式关卡配置和 UI

正式首领关卡规划维持直线：**小兵战一 → 小兵战二 → 村民补给 → 首领战**。本轮只使第一阶段可实际执行，不因为系统支持分叉就额外加入分叉、宝箱或剧情节点。

- 使用稳定地下城 ID 与节点 ID，独立于此前通用最小测试地下城。测试进度和奖励不能串到正式关卡。
- 第一节点引用实际可用的小兵战配置，不使用未替换的测试占位 ID，不引用最终首领敌群。
- UI 延续正圆、图标视觉居中、已完成绿色 √ 蒙层、当前可进入节点朱红单边框；无详情面板或额外进入按钮，点击节点直接启动。
- 第一场胜利后只标记该节点完成，将进度推进为第二阶段可继续。第二场节点本轮可作为明确的后续预留显示，但不执行第二场战斗、不伪装可正常挑战，不绑定不存在的执行内容。
- 优先使用工程已有的预留/未接入状态表达；没有该能力时，只显示当前已接入节点，并在返回结果中保留第二阶段进度。不要为临时预留扩建通用锁定系统。
- **第一节点完成绝不等于整个地下城完成。** 本轮不能把截短配置中的空后续误判为正式终点；不得派发地下城通关、首领胜利或主线完成结果。说明采用的阶段边界，方便下一步扩充配置。

## 4. 第一场战斗与胜负

- 点击当前第一节点后仅启动一次已有战斗实例，执行期间禁用冲突操作及重复点击。
- 以当前角色真实生命和资源进入，战果写回权威状态；胜利回节点图后保留生命和消耗，不自动满血。
- 胜利才完成节点、发放该场配置奖励并推进阶段；奖励与完成进度一致提交，重复回调或再次进入不重复结算。
- 战败或撤退不推进、不发胜利奖励，按工程现有规则重试第一节点。若尚无明确战败恢复规则，沿用通用地下城约定的战前安全快照，不新增复活经济。
- 成功回节点图后不自动开第二场战斗；本轮不实施补给或治疗。

## 5. 主线、日期与恢复

- “山贼来袭”在第一场胜利前后均保持进行中，目标保持“击败山贼首领”。第一场小兵不算首领死亡，不发主线完成奖励。
- 保留接取时的开始日和到期日，进入地下城、战斗胜利和暂离都不重新计时；普通战斗不额外推进日期。
- 第一节点胜利、单场奖励和第二阶段进度接现有持久化；在节点间安全状态按已有自动保存规则提交，不开放战斗中途存读。
- 退出重进正式入口后，已经胜利的第一节点继续显示 √，不得重复挑战领奖，进度不退回开局。第一战失败仍按当前未完成阶段恢复。
- 保护此前主线、外围战、存档改造及真实旧档。存档最终验收由用户负责，实施方仍完成本步必要自检和接线说明。

## 6. 完成标准

1. 第二战未完成时不能进入，完成后地图原首领入口打开正式地下城节点图。
2. 点击第一节点进入正确的小兵战，重复点击只启动一次。
3. 胜利回节点图，第一节点有绿色 √，下一阶段进度正确，生命与消耗保留。
4. 失败可重试，进度和奖励不提前提交；重复胜利回调不重复发奖。
5. 暂离再进入不丢第一节点完成进度，不串用测试地下城状态，不重置期限。
6. 第一战完成不触发正式通关、首领死亡或主线完成，未接入的第二场不会被实际启动。

交付实际 Unity 截图或短视频：从地图入口打开节点图、第一战启动、胜利后节点状态与气血；附正式配置 ID、修改摘要、自检结果及未解决项。不得以静态检查或浏览器模拟替代实际运行验收。

完成后停止在第二阶段接入前，后续三阶段另行下发。
