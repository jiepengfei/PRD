# Step 03：第二场山贼战斗与首领入口开放

日期：2026-11-05  
状态：供用户评审；本次只整理需求，未上传仓库或通知远程执行。

## 1. 本次目标

承接 [Step 02：第一场山贼战斗与任务推进](Step02_第一场山贼战斗与任务推进.md)，完成：

**第一战胜利 → 第二名山贼所在砖块翻面展示 → 点击主线聚焦第二名山贼 → 到达触发第二战 → 胜利更新主线目标并开放首领入口。**

本轮止于首领入口开放，不接首领关卡、补给、村长、结尾、宝箱支线或五日超时后果。开始实施前核对 Step 02 的执行结果，沿用其已有能力，不重复制作第一战。

## 2. 第二名山贼的开放与展示

- 使用山区附近的第二战锚点，配置真实逻辑地图 ID、砖块坐标、山贼展示及已有战斗配置。点位须可达、可通行，不放在山体内。
- 第一战胜利、同一主线进入第二战阶段后，第二战入口变为可触发，目标砖块直接使用现有翻牌效果揭示并显示山贼。
- 只揭示第二名山贼所在砖块，不额外翻开周围或通往该处的路径；已揭示时只刷新展示，不重复翻牌。
- 揭示不等于到访，不移动角色、不扣行动点、不直接开战；首次实际进入仍按原有行动点与到访规则处理。
- 第二战开放前不能通过提前探索、经过目标格或直接调用交互绕过第一战。普通探索可揭示地形，但不提前开放本事件。
- 本条是对 Step 02“只绑定第二目标锚点、暂不揭示和接入战斗”的后续补齐。两步合并后，第一战胜利既更新目标，也开放并揭示第二战；不是再要求玩家重打一遍第一战。
- 已处于第二战阶段的进度，在地图就绪后补齐第二战展示与揭示，不重接任务、不重置期限、不重复结算第一战。第二战已经完成的进度不得复活该山贼。

## 3. 点击主线定位

- 主线当前目标为第二名山贼时，点击地图主线条目，使用 Step 02 已接入的任务定位能力聚焦第二战锚点，并显示已有选格/目标高亮反馈。
- 任务面板已有定位入口也使用同一目标数据。坐标来自配置，不写死预览像素位置。
- 定位只移动镜头，不移动角色、不扣行动点、不启动寻路、不触发战斗或额外翻开其他砖块。
- 任务 UI 消费本次点击，不能穿透地图；重复点击不叠加镜头动画，手动拖动镜头可打断过渡。
- 第二战开放时不强制拉走镜头，由玩家点击主线主动定位。

## 4. 第二场战斗

- 主线处于第二战阶段且该遭遇未完成时，玩家实际到达目标砖块，停止后续移动并启动已有第二场战斗。寻路经过时同样检查，不能直接穿过。
- 查看详情、点击定位、翻面展示都不算进入或完成战斗。
- 复用已有战斗模块与配置；进行中阻止地图操作及重复启动。同一遭遇只运行一个战斗实例。
- 胜利才清理山贼、结算对应奖励并推进主线。战败或撤退不清敌、不推进，按工程既有规则返回和重试。
- 战果写回角色权威状态，保留正常生命与消耗，不因回地图意外满血或恢复为旧模板。
- 使用稳定遭遇 ID 和既有防重能力；重复回调、重进地图不能重复奖励或重复推进。

## 5. 胜利后更新任务与首领入口

- 同一条“山贼来袭”保持进行中，当前目标更新为“击败山贼首领”。不新建同名主线、不完成整条主线、不发放主线最终奖励。
- 清除第二名山贼的未完成遭遇表现，保留该格的揭示和到访状态，之后经过不再触发第二战。
- 任务列表、悬浮栏和定位引用同步切换至首领入口，不再定位第二名山贼。
- 第二战胜利即开放首领入口，不等待五日到期。开放条件由当前进度控制，不依赖首领图标是否成功生成。
- 首领入口绑定稳定事件/入口 ID 和可达的地图锚点。该格已揭示时显示现有首领标记；尚未揭示时保持迷雾，本轮不主动翻面首领格或周边。
- 点击更新后的主线可聚焦首领入口锚点，但不移动玩家、不揭示迷雾、不触发首领战斗。
- 本轮只完成入口显隐、定位和基础详情。详情可说明“山贼首领据点”；首领关卡尚未接入时，不提供有效的“开始挑战”操作，使用明确的暂不可挑战提示，不能让按钮无响应或直接跳最终首领战。
- 玩家提前经过或点击首领位置，不能绕过第二战开放条件，也不能被空流程卡住。本轮不增加首领入口阻挡移动的规则。

## 6. 日期与进度接线

- 保持主线接取时记录的开始日与到期日，第二战开放、胜利及首领入口开放都不重新计算五日期限。
- 普通战斗不额外推进游戏日期；已到期状态不因本步推进恢复为新的五日倒计时。
- 第二战胜利、奖励结算、事件完成、主线目标及首领入口开放作为一致结果提交，接入现有进度与存档接口。
- 地图重建按已保存进度恢复正确阶段，不复活已完成山贼，不把已开放首领入口重新隐藏。恢复展示本身不重复发奖、弹出接取通知或强制移动镜头。
- 保护已有第一战、任务、倒计时及存档改造，不另写一套临时存储。存档最终验收由用户负责，实施方完成本功能必要自检。
