# Step 05：第二场小兵战、村民补给与最终首领战

## 1. 范围与前置

在已有正式首领地下城和第一场小兵战基础上，补齐：

**小兵一已完成 → 小兵二 → 村民补给 → 最终首领战 → 地下城完成 → 返回地图，完成“山贼来袭”主线。**

本步合并此前待办 1、2、3。前置是地下城配置化执行和 Step 04 已跑通；实施前先核对实际执行报告，不把已下发当成已完成。

本轮主要改正式关卡配置、补给结果及首领胜利回传，不新建地下城或任务系统。若前置尚未完成，先明确缺口再顺序接线，不能并发重写同一工程。

不加入五日超时烧抢、悲愤、村长、出口、送别、访仙缘、分叉扩展或新战斗机制。补给缺少正式 CG 时使用已有通用对话直接接通，不把新美术制作加入本轮。

## 2. 正式关卡配置

沿用同一地下城 ID，保留第一节点的稳定 ID 和已有进度，补齐后续三个节点。正式关卡仍为四节点直线，不额外插入宝箱或支线。

| 节点 | 内容 | 成功结果 |
| --- | --- | --- |
| 小兵一 | 已有第一场小兵战 | 保持原结果，开放小兵二 |
| 小兵二 | 第二场小兵战 | 记录完成，开放补给 |
| 村民补给 | 短对话与一次性治疗 | 治疗至当前有效生命上限，开放首领战 |
| 最终首领 | 首领战 | 完成地下城，回传首领胜利，完成主线 |

- 引用工程实际可用的敌群/战斗配置，不能直接把最终首领当第二场小兵，也不能保留未替换的占位引用。
- 已完成第一节点的进度继续开放小兵二，不重打小兵一，不重发其奖励。补齐 Step 04 的后续预留状态，不创建另一份正式关卡。
- 每个节点成功后先回节点图，更新绿色 √ 与下一个节点的朱红单边框，由玩家点击继续；不自动串开下一战。
- UI、图标和输入规则沿用第二版定稿，不新增面板、额外进入按钮或场景美术。

## 3. 第二场小兵战

- 第一场胜利后才可进入，其他调用不能跳过第一场。
- 使用当前角色真实气血与资源开战，跨场保留消耗，不自动恢复满血。
- 胜利后写回战果，结算对应单场奖励一次，完成第二节点，开放补给。
- 战败或撤退不推进，按已有地下城战败规则重试当前节点，不重打已经完成的第一场、不重领此前奖励。

## 4. 村民补给

- 第二场胜利后可进入。点击补给节点，使用已有通用对话组件播放短对白，背景可选，不强制新建 CG。
- 本稿接线对白建议：村民：“少侠，带上这些药和干粮，先歇一歇。”主角：“多谢。你们先回村，剩下的交给我。”这是草案，可在配置中替换。
- 对话正常结束或使用既有跳过能力后，执行一次治疗，将气血恢复至**当前有效生命上限**；不修改基础上限，不恢复行动点、货币或其他未约定资源，也不强制发放道具。
- 治疗结果、补给领取和节点完成一致提交，再开放首领战。对话打开、被异常中断或结果失败不算领取完成。
- 领取后加绿色 √，不可再次进入刷治疗。重复回调、暂离重进不重复生效；首领失败重试也不能重新领补给。
- 如果工程已有其他属性修正，治疗服从修正后的有效上限，但本轮不新增悲愤状态或超时逻辑。

## 5. 最终首领战

- 补给节点完成后才可进入，不能从地图首领入口或旧 UI 直接绕过前面节点启动最终战。
- 使用补给后及玩家当前的真实状态进入，沿用现有战斗和单场奖励能力，不在本步制作新首领技能体系或平衡整套卡牌。
- 战败/撤退不完成地下城和主线，重试当前首领节点；沿用既有战败规则。若该规则采用战前快照，恢复的是本次首领战前状态，不能重新执行补给节点。
- 胜利后提交首领被击败、节点完成、地下城完成和相应奖励；重复战果回调不能重复完成或发奖。

## 6. 通关回传与主线

- 最终首领是本关唯一终点。完成首领节点后，由地下城执行器向地图流程回传成功结果，再由已有主线接线完成同一条“山贼来袭”。
- 不能在小兵二胜利、补给结束或 UI 关闭时提前发通关结果。不得把任务阶段变更计成多次主线完成奖励。
- 单场战斗奖励和主线奖励按已有配置分别结算，责任边界明确，不能在战斗返回、地下城结束和任务完成三处重复发同一份奖励。
- 正常返回原地图安全落点，主线显示已完成，首领入口表现为已清理/已完成，不再启动这条一次性关卡。不自动开放村长后续或离村出口。
- 若来袭日期事件仍待发生，首领胜利时取消并刷新顶部事件栏，不能在稍后到期再次触发。若事件已到期或后果已经发生，保留该事实，不回滚既有后果；本轮不新增后果处理。
- 进入与完成节点不重置开始日/到期日，普通战斗不额外推进日期。

## 7. 进度与防重

三个后续节点接入已有地下城进度与存档服务。节点结算完成、回节点图稳定后，按现有安全边界自动保存；禁止战斗或对白中途保存。

暂离重进时从当前未完成节点继续，已完成小兵和补给保持完成，不重新开放。最终首领胜利后即使重复返回、重新开 UI 或重复结果回调，也不能重开一次性关卡或重复奖励。

保护已有存档、主线和外围战进度。存档最终验收由用户负责，实施方完成本功能必要自检，报告接线范围与未解决项。

## 8. 完成标准

1. 已完成小兵一的进度可直接继续小兵二，不重打、不重奖。
2. 小兵二胜利后开放补给，气血与消耗跨战斗正常保留；失败只重试当前战斗。
3. 补给正常播放/跳过均治疗到当前有效上限且只生效一次，之后开放首领。
4. 首领不能提前进入；战败不通关、不重新领补给，胜利才完成最终节点。
5. 最终胜利只回传一次，返回地图后同一主线完成，任务及单场奖励不重复，未到期来袭事件取消。
6. 节点图状态、顺序及原进度兼容正确，不新增未约定的主线后续、超时剧情或战斗系统。

交付一段实际 Unity 连贯演示或关键截图：继续小兵二 → 补给回血前后 → 首领胜利 → 回地图主线完成与事件栏更新；附配置 ID、修改摘要、自检结果和缺口。若无正式 CG，明确说明采用临时对白表现，不报告为最终美术完成。

本步完成后停止。村长、出口与结尾另行安排。
