## 本版视觉

自动存档排最上方。存档条目两侧同向斜切，轮廓带自然起伏；左下和右上保留飞白，长度按4:6分配。选中浓绿、未选中淡灰绿，保留当前宽高与颜色。主按钮为实心不规则笔触，取消按钮为同类浅墨笔触。返回为较厚朱圈加短粗X，与标题水平中心对齐。右侧详情保留干净纸面。

## 交付边界

文字均由程序独立显示，包括标题、存卷印中文字、存档名称、日期、地点、气血、行动点、Tab与按钮文案；这些文字未烘焙进正式PNG。朱圈和X属于拆分的图形。

PNG为当前浅色水墨主题，按2倍输出，不包含另一套深色主题。笔刷、按钮、山影与图形素材具有真实Alpha；纸面本身是不透明设计。没有从带水印的参考图抠取素材，笔刷由当前预览的原生绘制算法导出。

**只交付美术、布局和导入说明，不含Unity Prefab、.meta或真实存读功能。尚未在目标Unity工程验收。** 预览中的3个手动位、自动档管理限制等是界面示例，存档业务需求仍待确认，不得据此擅自开始实现。
