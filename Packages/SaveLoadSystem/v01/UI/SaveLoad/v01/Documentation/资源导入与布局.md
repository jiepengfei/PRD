# 资源导入与布局

## 1. 目录与状态

所有正式图片在`Assets/WuxiaVillage/Art/UI/SaveLoad/`，按Backgrounds、Panels、Buttons、Icons、Decorations分类。先确认目标工程实际目录映射，复用同源资源，保留已有.meta/GUID。本包不伪造Unity生成的.meta，不提供未验证Prefab。

`Reference`是带文字的浏览器还原参考，不作为整张UI贴图使用；`Source`是可编辑源稿和导出工具，不整目录导入运行时。

## 2. 资源使用

| 类别 | 使用方式 |
| --- | --- |
| 存档底图normal/selected | 两张轮廓与Alpha一致，仅颜色不同；切换Sprite而不改变RectTransform |
| 空白槽底图empty | 已含52%透明度，Image颜色Alpha用1，避免再次乘52%导致过淡 |
| 主按钮/取消按钮 | 图形与文字分离；Simple Image，文字独立居中；不强行统一按钮宽度 |
| 返回朱圈/X | 同为80×80像素、显示40×40单位；在相同矩形上叠放，不能各自裁透明边后居中 |
| Tab下划线 | 独立笔触图，显示在当前Tab文字下方；Tab文字不是贴图 |
| 详情/确认纸面 | 可用Sliced，Border建议四边各4源像素；实际按已有UI导入器校验 |
| 宣纸背景 | 无内容，参考显示850×752；Simple按窗口整体适配，不按九宫格拉伸纹理 |
| 淡墨山影 | 透明装饰，已烘入预览的淡化效果；Image Alpha保持1，不重复乘透明度 |
| 小印边框 | 不含“存卷”文字；文字另放，组件旋转约-4°；字体复用工程已有中文字体 |
| 确认遮罩 | 128×128 RGBA，可拉伸全屏；Alpha已为0.4，Image Alpha设1 |

PNG均为2倍导出，显示尺寸以`Data/save_load_layout.json`的参考矩形为准，不能直接SetNativeSize当成最终尺寸。存档笔刷禁止九宫格切片，避免破坏斜边和飞白；保持参考宽高比并随整体窗口缩放，勿单独压扁笔刷。

## 3. 导入建议

Sprite (2D and UI)、Single、Full Rect、sRGB开启、Alpha Is Transparency开启、Bilinear、Clamp、无MipMaps。基准无损/不压缩，Max Size至少2048，不能被平台覆盖设置缩小。PPU默认100，但以工程UI约定为准，不用地图Tile的256 PPU决定UI显示大小。

所有状态的Image颜色默认为白色/Alpha1，使用PNG自带颜色；不要再次Tint成灰绿导致颜色翻倍。若后续改主题，应从源稿重新导出或使用专用Alpha遮罩方案，不能直接把当前有色Sprite作为另一主题定稿。

## 4. 参考布局

参考窗口为850×751.75 UI单位，PNG参考图按2倍导出为1700×1504。坐标原点为窗口左上；Unity本地Y向上，使用时转换坐标或按锚点布局。

- 标题在左上，朱圈X中心与标题中心同高；二者对齐误差在本次浏览器检查为0。
- 上方读取/保存Tab，下方左右两栏；左侧存档列表，右侧详情。
- 自动存档在列表最上面，之后为手动位一、二、三。数量只作预览，不是已确认的系统容量。
- 每个存档显示索引/类型、名称、日期及地点，文字叠在笔刷中段，避开两侧飞白。
- 详情区包含类型/游戏日、名称、地点、气血、行动点、简述与保存时间；数据均为示例。
- 底部主按钮右对齐，取消与确认在二次确认弹窗右下方。
- 具体矩形、字号、行距及字体回退见布局JSON。参考采用系统宋体/微软雅黑，字体文件未打包；目标工程复用已有中文TMP字体并实测排版。

建议层级：

```text
SaveLoadWindow（接入既有UI栈）
├─ PaperBackground
├─ Header：TitleText / SealFrame+SealText / Mountain / ReturnCircle+ReturnCross
├─ Tabs：LoadText / SaveText / ActiveUnderline
├─ SlotList：SlotBackground + IndexText + NameText + MetaText
├─ DetailPaper：各项独立文字
└─ PrimaryButton：Background + Label

OwnedConfirmation（按既有父子窗口规则接入）
├─ Scrim
└─ ConfirmPaper：Title / Message / CancelBackground+Label / ConfirmBackground+Label
```

窄预览采用上下布局，已检查360像素无横向溢出；此结果不代表Unity全分辨率验收。生产最低分辨率和CanvasScaler沿用目标工程规范。
