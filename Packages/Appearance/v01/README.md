# 外观选择界面美术组件

日期：2026-11-23 · 版本：v0.1

本包按用户确认的水墨外观界面整理组件。战斗皮肤与整套卡牌风格分别切换。皮肤内容的预览由 Unity 实例化选中皮肤对应的 Prefab 生成。

## 文件

- `Requirements/外观系统需求.md` 说明两类外观切换、配置、存档、真实Prefab预览与验收范围。
- `Assets/` 提供8张界面组件PNG，包含宣纸、列表普通/选中/使用中底板、应用按钮、使用中标记、Tab笔触及可选详情纸面。
- `Data/asset-manifest.json` 记录尺寸、Alpha与用途。
- `Data/layout.json` 记录参考布局、配色与状态叠加规则。
- `Documentation/Prefab组装与预览说明.md` 说明窗口、条目及实时预览的组件关系。
- `Source/export-components.cjs` 从原生界面轮廓导出图片，宣纸资源复用已有存读界面美术。

包内图片只承载界面底板与装饰。名称、说明、获取状态、勾号、使用中、应用按钮文案由中文文字组件显示。使用中采用醒目的实心绿色标记，当前查看与实际使用状态分别绑定。

本包排除了浏览器预览、示例皮肤图片、示例卡牌配色和静态预览截图。皮肤Prefab与实际Unity窗口需在目标工程里组装，当前交付没有伪造Prefab、.meta或字体，也没有完成Unity接入。

## 导入

复用工程资源目录与已有GUID。新增PNG使用Sprite/UI、Single、Full Rect、Bilinear、Clamp、sRGB、无MipMaps，保留Alpha。程序使用白色Image颜色以呈现PNG原色。

列表和按钮轮廓按2倍参考尺寸输出。沿用长宽比例随窗口整体缩放，避免九宫格扭曲笔触。纸面背景等比适配，可选详情纸面允许按清单做九宫格。字体使用目标工程已有中文字体。

原浏览器方案的额外皮肤名、已获取数量及新增风格都属于演示数据，正式列表从真实配置和解锁记录生成。
