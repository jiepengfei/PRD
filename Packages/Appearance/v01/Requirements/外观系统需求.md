# 战斗皮肤与整套卡牌风格切换需求

日期：2026-11-23 · 版本：v0.1

## 目标与范围

在现有“我的”中提供“外观”入口。玩家可以查看战斗皮肤和整套卡牌风格，自由切换已获取的外观；两个分类分别选择、分别保存。

本次完成配置、窗口、真实Prefab预览、应用和存读恢复。复用已有UI栈、资源加载、解锁记录和存档系统。交付使用现有真实美术，不要求新增皮肤，不扩展商城、付费或新的解锁玩法。

## 两类外观

| 分类 | 替换内容 | 约束 |
| --- | --- | --- |
| 战斗皮肤 | 由配置引用的战斗展示Prefab及其美术组件 | 先核对现有战斗视图，复用数据绑定与交互接口，不改变战斗规则 |
| 卡牌风格 | 整套卡牌展示Prefab，包括卡面框架、卡背、文字与数值布局、选中等表现 | 一次替换整套风格；卡名、费用、描述、效果和已有卡牌立绘继续从真实卡牌数据绑定 |

外观只改变表现。不得改变卡组、卡牌效果、敌人属性、奖励、行动顺序、目标选择和点击规则。整套卡牌风格需覆盖实际用到的卡牌状态，保持文字可读与交互可用。

## 窗口与操作

沿用资源包中的宣纸、墨绿配色和组件轮廓。左侧是按配置生成、可滚动的外观列表，右侧显示所选外观的真实预览、名称、获取状态与说明，底部为应用操作。两类Tab为“战斗皮肤”和“卡牌风格”。

1. 打开分类时默认选中该分类当前使用项。
2. 点击列表条目只切换预览，点击应用才更换实际使用项。
3. 已获取项可自由应用；未获取项可预览，应用入口禁用并显示“未获取”。获取状态读取已有记录，不另建一套解锁流程。
4. 当前查看与实际使用分开表达：当前查看有选中侧线；实际使用有绿色底板和醒目的实心绿色“✓ 使用中”标记。查看其他项时，原使用项仍保留标记。
5. 右侧显示对应分类当前使用的真实名称。预览项等于使用项时也显示绿色标记，按钮显示“使用中”且不可重复应用。
6. 应用成功后同步更新列表、右侧状态与存档；关闭重开保留使用选择。沿用已有窗口返回和Esc优先级。

## 配置与数据

建议沿用项目现有配置形式表达下列最小字段，命名可适配工程：

| 字段 | 用途 |
| --- | --- |
| skinId | 稳定且唯一的外观ID，供存档引用 |
| category | 战斗皮肤或整套卡牌风格 |
| displayName、description | 名称和展示说明 |
| prefabRef | 实际使用的Prefab资源引用 |
| sortOrder | 列表排序 |
| unlockKey | 关联已有获取记录；默认项可直接可用 |

每类需有一个明确的默认项。获取记录复用既有结构；保存各分类当前使用的skinId，避免将资源路径或Prefab实例写入存档。选中预览项属于窗口临时状态。

旧档缺少外观字段时补默认值，不改变原进度。配置项删除、ID无效、外观不可用或资源加载失败时回退该分类默认项，避免空白战斗或无法打开卡牌。默认项必须随游戏可用。

## Prefab实现与预览

窗口、Tab、列表条目、预览容器与按钮以Unity组件和Prefab组装。实际外观也由配置引用的Prefab组成，展示数据由现有系统绑定，不把逻辑和数值复制到每套皮肤里。

右侧预览必须实例化选中外观的真实Prefab。战斗使用固定展示数据，卡牌用相同的一组代表卡数据对比整套风格，至少展示多个正面与卡背。预览和正式使用共用真实外观资源；若需要专用预览Prefab，它应引用真实组件，避免维护两套样式。

依据现有渲染结构选择独立UI裁剪容器，或隔离相机加RenderTexture。预览仅展示，不启动战斗、不扣资源、不发奖励、不写游戏进度，也不接管地图操作。切换及关闭时清理旧实例、订阅和临时渲染资源。

列表缩略预览可由同一真实Prefab流程生成并缓存。当前浏览器方案中的示例皮肤图片、配色滤镜、皮肤名、解锁数量和静态截图都不纳入正式内容；不得用它们代替真实Prefab预览。

## 生效时机与存读

应用后保存两个分类各自的选择，下一场战斗构建视图时使用。战斗进行中不热替换已有实例，避免中途破坏动画和输入状态。若入口在战斗中可访问，应提示“下场战斗生效”。

读取存档按已有生命周期恢复选择，再构建对应视图。返回标题及重新进入游戏时，不残留上次预览实例或未保存的窗口临时选择。两个分类互不覆盖，应用同一项不产生重复副作用。

## 美术与交付

本包Assets提供8张界面组件PNG；文字、勾号和状态由文字组件渲染。尺寸配色参见Data，组装细节参见Documentation。使用目标工程现有中文字体，沿用UI缩放及目标分辨率适配方式。

包内尚未包含Unity Prefab和工程接入代码，需在实际Unity工程中完成。实现后提供改动说明、实际配置ID、实际Unity界面演示、必要检查结果及未解决项。

## 验收

- 两个分类从真实配置生成列表，已获取项可分别替换，切换卡牌风格能覆盖整套卡牌表现。
- 预览实际Prefab与正式显示一致，切换预览不等于应用；绿色“使用中”在浏览其他项时仍然清晰。
- 应用、重开窗口、存档读取后选择正确；旧档和无效ID可回退默认项。
- 下一场战斗使用选中的两类外观，数值、卡牌效果和既有交互保持正确。
- 预览切换和关闭无残留对象或逻辑副作用；必要范围内验证即可，不做无关的大规模回归。
