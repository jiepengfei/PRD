# 侠客行封面、我的菜单存读入口与 Esc

日期：2026-11-09 · 版本：v0.1 · 状态：需求与美术交付，本次只上传，不通知实施。

## 1. 本轮目标

接入已选定的《侠客行》简笔水墨封面菜单；把游戏内保存、读取入口放进已有“我的”菜单；增加 Esc 打开/关闭“我的”，并沿用 UI 栈的层级消费规则。

复用现有标题/首页生命周期、我的菜单、存档服务、存读 UI、设置和音频系统。不新造存档框架、不扩展战斗或剧情。本稿取代旧存档需求中“游戏内暂停/菜单入口”的泛指表述，明确游戏内入口位于“我的”。标题页仍提供继续游戏及读取存档。

## 2. 视觉定稿与资源

采用已确认的 v03 构图：左侧“侠客行”书法及纵向菜单，右侧简笔水墨背剑人物，淡墨山峦、松枝和纸面留白。人物保持简笔画风，不恢复写实衣料和繁密背景。

- 背景、标题/小印、选中笔触与菜单文字分离。美术包提供无文字背景和独立透明资源；定稿整图只作参考，不能直接作为可交互 UI 使用。
- 菜单文字由工程已有中文字体独立显示；标题使用已给定的书法资源，保留字体风格。菜单选中笔触复用已交付的水墨笔刷轮廓，文字与其分层。
- 不新增“我的”页面视觉改造，本轮只在其现有布局中增加或复用两个入口，避免另做一套暂停菜单。
- 分辨率适配保持图片比例，不拉伸人物；超宽/窄屏时菜单保留安全区域，不能将标题或按钮裁出屏幕。基准布局见美术参数，不以概念图像素写死所有分辨率。
- 首版静态背景，菜单可使用现有轻量 hover/选择反馈，不新增人物动画或动态天气。

## 3. 标题菜单行为

| 菜单 | 行为 |
| --- | --- |
| 开始游戏 | 创建新游戏会话，进入已有练剑开场；不删除或覆盖旧手动档 |
| 继续游戏 | 读取最近保存的有效档，自动档与手动档均参与，以真实保存时间判断；无有效档时禁用 |
| 读取存档 | 打开已有存读窗口的读取 Tab，无存档也可查看空位，不能保存 |
| 设置 | 打开工程已有设置界面，不另造设置系统 |
| 退出游戏 | 使用既有二次确认退出程序；取消留在标题，编辑器测试不得关闭编辑器 |

“有效档”按已有存档服务校验，损坏或不兼容档不作为继续目标；查询失败应有反馈，不能当作没有档并清空数据。读取失败留在可操作界面，不悄悄启动新游戏。

启动进入标题，不能因为旧存档存在而自动跳过标题；每次返回标题重新查询存档，更新继续按钮和读取列表。新游戏确认只处理放弃当前会话，不擅自清空旧槽位；新会话正常自动保存仍遵守既有自动档规则。

## 4. “我的”内的存读档入口

- 在现有“我的”菜单加入“保存游戏”“读取存档”，保留原有背包、人物、任务等已有功能。
- 保存游戏打开现有存读窗口的保存 Tab；读取存档打开读取 Tab。不得复制另一套槽位窗口、另造保存文件或写死槽位数量。
- 关闭存读窗口回到“我的”；存读二次确认的取消只关闭确认框，不能连带关掉两层。使用已有父子窗口归属维护，不手写并行窗口栈。
- 保存/读取是否允许继续调用现有服务的忙碌校验。地图空闲、已支持的地下城节点间安全状态按原规则操作；执行事件、切图、战斗、CG、对白、存读过程中不得绕过限制。
- 按钮不可用时提供已有禁用反馈/原因；读取成功后关闭存读相关窗口与“我的”，恢复目标存档场景和状态，不能残留输入遮挡。
- 游戏内既有独立/悬浮存读按钮统一收敛到“我的”，避免重复入口；底层兼容方法不必删除。标题的读取入口保留。实施前核对现有 SaveLoadEntryPoints 实际挂接，不凭旧报告猜屏幕位置。

## 5. Esc 快捷键及输入归属

按现有 UI 栈与流程锁处理，每次按键只由最高优先级目标消费一次：

1. 有确认框、预览或其他上层窗口时，先执行该界面原有返回/关闭行为；同一次 Esc 不继续打开“我的”或取消地图动作。
2. “我的”已打开且无其上层窗口时，Esc 关闭“我的”，恢复原有输入状态。
3. 游戏内没有上层窗口且无冲突流程时，Esc 打开“我的”，不叠开多个实例。
4. 地图正在执行可取消移动/寻路时，沿用原有 Esc 取消行为并消费本次按键，停稳后再按 Esc 才打开“我的”。不在同一帧同时取消和打开。
5. 战斗、CG、对白、强制选择、切图与存读期间按原有流程/输入锁处理，本轮不增加这些场景打开“我的”的能力，也不劫持其原有 Esc 操作。
6. 标题页和 Demo 结束页不通过 Esc 打开游戏内“我的”；其子窗口的返回仍遵守原规则。

复用唯一输入分派入口，不能在“我的”、存读窗口和地图 Update 中分别监听同一 Esc 导致多层同时响应；长按与重复回调不得连开连关。UI 的点击与 Esc 都不能穿透到地图。

## 6. 返回标题与音频

接通当前 Demo 结束后的既有返回标题入口；复用已有会话清理，停止旧地图/战斗/剧情调度，关闭游戏内窗口，释放输入锁和旧回调，再回标题刷新存档摘要。

不能清空磁盘档或误触发旧流程结算；从标题再次新游戏/读取时不得继承上一会话的临时对象。已有存读恢复接口优先复用，必要时补最小生命周期接线。

按钮声音复用已接入的非战斗音频映射；通用 UI 和业务音去重。沿用已有音乐策略，不要求本轮创作标题 BGM 或扩建音频系统。
