# 对话 UI 资源包

[下载 Wuxia_DialogueUI_Art_Animation_v01.zip](Wuxia_DialogueUI_Art_Animation_v01.zip)

定稿为缩小立绘、人物从底部弹出、对白框下落并放大回弹的版本。

资源包包含：

- 8 张独立 PNG：背景、底部渐变、主角立绘、对白框、衬板、姓名牌、跳过按钮底、继续箭头。
- 同一布局的静态图和动画 GIF 参考。
- Unity 资源导入与布局说明、动画接入说明、布局及动画 JSON 参数。
- 可编辑图形源稿、网页动画参考代码和资源校验清单。

解压后先阅读包内 `README.md`。素材接入位置遵循目标 Unity 项目已有规范；姓名、台词等文字由程序渲染。本包不包含 Unity Prefab、运行时代码、字体或开场视频，未在目标 Unity 工程中测试。
