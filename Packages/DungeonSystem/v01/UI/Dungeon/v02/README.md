# 地下城 UI 与图标 · 第二版定稿

日期：2026-11-05。选用用户提供的第二套「简约平涂」图标。

## 内容

- `Assets/Icons`：10 张 256×256 透明 PNG，含战斗、首领、宝箱、剧情、符牌、探索、商铺、锻造、补给、传送。未使用的图标只作资源预留，不要求本轮开发对应系统。
- `Assets/Backgrounds`：无文字的纸面背景 PNG，按参考画布 2 倍导出；可复用已有同风格背景，不将带文字截图当背景。
- `Source/user-flat-icon-sheet.png`：用户提供的原图，保持原样；原图有黑底，独立 PNG 已转换 Alpha，导入时需检查边缘。
- `Source/dungeon-approved.html`：单版线性 UI 可编辑预览，使用本包透明图片，无对比切换。仅模拟点击反馈，不是真实地下城。
- `Reference`：定稿还原截图、十图标总览、分叉布局示意。
- `Data`：图标清单、视觉参数和最小节点配置样例。字段供实施映射，不是经过工程验证的运行时格式。

## 导入与组装

使用目标工程已有目录与规范，保留已有资源 GUID，不整张图集贴进节点。Sprite/UI、Single、Full Rect、sRGB、Alpha Is Transparency、Bilinear、Clamp、无 MipMaps；透明边不能裁切为 Tight 后改变视觉对齐。默认 PPU 100，最终遵循工程约定。Image 白色/Alpha 1，避免图标被重复染色。

图片保留透明留白，参考圆直径 80 UI 单位、图标矩形 60×60。实际可见图形略小于矩形，按 Data/visual-layout.json 为每种图标分别设置视觉偏移，不能只做矩形居中。PNG 不烘焙圆框、连接线、完成蒙层、绿色 √ 或文字。

圆框由程序生成，正常边框灰绿 #ADB6A2，当前可进入边框朱红 #A8523D，只有一层，均为正圆。完成蒙层参考 #E1E6DA/79%，√ 使用 #28864D。不得给已关闭的未选路线加完成 √。

标题、计数和类型名称使用工程已有中文字体独立显示；无需详情面板、进入按钮或解释状态的常驻文字。点击可进入节点直接执行业务，预览反馈不能当作功能实现。

支持配置生成直线、分叉和汇合；分叉示意不是关卡定稿。Unity 需实测布局、字形、Alpha 边缘、命中、滚动/平移和不同分辨率。本包未进行 Unity 验收，不包含字体、Prefab 或 .meta。
