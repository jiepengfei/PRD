## 接入现有播放系统

不附第二套音频框架或游戏源码补丁。把 WAV 导入现有 SFX 目录，通过稳定 ID 映射现有资源 Key；具体工程路径、Mixer、AudioSource、加载模式与 GUID 需在实际工程核对，不在此虚构。保留既有 .meta，新导入由 Unity 生成。短UI音建议2D、非循环、pitch=1；移动落地默认同样按2D起调，空间化留到实机判断。

manifest 中 volume 为 0—1 线性播放增益，文件峰值已保留9—16dB余量，不再统一归一化到0dBFS。主SFX总线起调后再结合BGM调音。建议全局最多4声部，留1个给错误/章节等高优先级；同变体组最多1个，不为换变体绕过冷却。优先丢弃脚步、翻牌、选择等低优先级声音。冷却基于不受游戏暂停影响的单调时间；一操作一个业务结果音，用 session + operationId + semanticOutcome 去重，成功事务去重标记保留到本次会话结束。无operationId时使用现有业务唯一提交记录，不用只靠短冷却模拟幂等。

同事务推荐选择顺序：错误 > 章节完成 > 非战斗任务完成 > 补给/开箱 > 奖励到账 > 普通进度 > 点击/选择。不是把这些音排队全放。业务按钮不挂通用点击，等待提交成功后播放业务音；失败只播拒绝音并显示原因。纯UI才播点击/确认。大型组揭示每批最多3枚，flip组100ms节流，后续只动画无声音。多物品奖励合并一枚，有铜钱选coin；开箱/任务完成自带结果反馈，抑制同事务coin/item。脚步、翻牌冷却跨变体共享，三步或两翻轮换避免连续同枚。

自动保存成功默认静默；需要声音时降低至0.25且让位于当前业务音。失败提示可有共享deny，自动失败最多10秒一次。保存成功必须是校验并替换正式档后，读取成功必须是整体状态恢复且地图就绪后。读取期间静默所有奖励、任务、首次揭示、落地、解锁与节点恢复音。

严格排除战斗来源：攻击、武器、命中、胜负、战斗结算奖励、战斗直接导致的任务完成/进度以及战斗节点完成√，均不挂本包声音。地下城“进入”仅指打开节点图；任务完成音仅用于非战斗目标。chapter_end 仅在送别提交后的章节结束页播放，不是胜利声。补给虽然位于首领关卡，属于成功恢复业务，不接战斗动作。

## 规格、复现与校验

全部单声道 44,100 Hz、16-bit signed PCM WAV、非循环。文件命名为 `sfx_<stable_id>_v002.wav`，ID不带版本号；变体组有独立group字段。没有包含Unity .meta、Prefab或项目设置。

在项目根目录运行：

```powershell
python Audio/SFX/v02/Source/build.py
python Audio/SFX/v02/Source/verify.py
python Audio/SFX/v02/Source/package.py
```

仅依赖 Python 3 标准库，固定每文件随机种子；同一Python环境内重建应有相同PCM与SHA-256。跨Python/libm平台的浮点末位差异可能改变个别量化采样，应重新生成校验，不宣称跨平台逐字节恒等。

verify.py 独立用标准库wave解码已写入文件，核对规格、帧数/时长、峰值、RMS、DC、削波、静音占比、首尾采样、首尾5ms最大相邻差值、引用及哈希。阈值与每文件结果在 QA/validation.json；验证数值不代表纸张/木质等听感已经合格。试听页存在性和路径检查不等于浏览器音频播放验收。请在实际耳机/扬声器逐项试听并在Unity内验收音量与并发后再替换占位状态。

checksums.sha256 包含包内所有交付文件（不含自身）；ZIP旁的SHA文件验证整个压缩包。源码、清单、试听页和检查结果一起打包。
