# 战斗结算页面接入需求

日期：2026-11-19。范围：胜利页、物品 Hover、失败页的显示与既有结果流程接线。

## 视觉与范围

以 Reference/victory-approved.png、victory-hover-approved.png、defeat-approved.png 为定稿。胜利标题仅「胜利」，朱红与暖金，禁止侠字印章；失败仅「失败」，冷灰墨。沿用山道暮色背景及中央暖纸竖面板。移除战斗 HUD，页面期间拦截战场操作。

本包不增加战斗规则、奖励生成、自动经验成长、新物品系统或复活系统。先核对实际工程入口、BattleResult、背包、通用 Tooltip、UI 栈与失败处理，复用原能力。工程已有行为优先，缺失项明确记录后补最小接线。

## 胜利与奖励

1. 自上而下：胜利标题 →「获得道具」及左右细线 → 四列物品格 → 底部「确定」。不分战利品/成长类别，不显示战斗统计、地图进度句或武学成长模块。
2. 所有实际应展示的货币与物品按配置的稳定顺序依次从左到右、从上到下排。使用权威奖励快照，不在 UI 随机掉落。相同可叠加条目按既有规则合并；不可叠加物品保留实例。无明确排序时保持结果返回顺序，不能每次刷新跳位。
3. 四列、每格约96×96，数量右下独立渲染；不常驻物品名称。数量按工程格式处理大数，不能溢出格子。少量物品保持网格起点和格距，不拉大成展示卡；无奖励显示「本次未获得道具」，不造奖励占位。
4. 超过八项时仅物品区滚动，标题与按钮固定；后续项必须可访问。未装满行不显示可悬停的虚假物品。数量和物品ID不写进素材。
5. 「心得」本质为经验药消耗品，按物品数量展示。结算页只发放/展示该物品，不自动消耗，也不把数量当经验值直接加到人物。使用及经验值由既有物品配置决定。本包不指定每份经验量，若工程缺该物品定义，映射/补齐实际配置后验收，不用截图猜数值。
6. 确定仅确认展示并继续原有返回路径。地图战返回地图，地下城战回原节点流程。按钮不触发第二次奖励、强制回血或额外任务推进。

## Hover / 焦点说明

1. 仅有真实奖励的格子可响应。鼠标进入约150ms后显示，格子叠2px朱红描边、轻暖色高亮，不放大、不挤动网格；按项目输入支持键盘/手柄焦点。无悬停设备可用轻触查看，避免触摸悬停后无法关闭。
2. Tooltip 独立浮层，暖纸底、细墨线、轻投影。依次为名称、类型、分隔线、实际用途/效果、描述、本次获得数量。缺少字段收起对应行。物品描述必须来自当前物品配置；铜钱显示货币说明，不套消耗品模板。
3. 心得示例：心得 / 消耗品 / 使用后可获得经验 / 修行感悟，助益精进。/ 本次获得：1。文字只作显示样例，实际经验量有可靠配置时可显示真实值。
4. 本包定稿在主面板右侧展示；工程需将Tooltip靠近当前物品可用侧，检查屏幕安全区，右侧不足翻到左侧，纵向夹紧。不能裁出屏幕、遮住悬停格或确认按钮。说明较长时换行并限高，必要时使用既有详情能力。
5. Tooltip不接收射线，不含「使用」「丢弃」「出售」等操作。移出、焦点切换、滚动、点击确定、关闭窗口或切场景时及时隐藏，清理延迟任务。悬停不发奖、不消耗、不存档。

## 失败页

1. 顶部「失败」，中间归剑插画及「胜败乃兵家常事」，底部左「返回」、右朱红主按钮「重试」。不显示战利品、经验或虚构损失。
2. 重试调用原有失败重试入口。原地下城约定：失败不推进节点，有既有规则按其执行；无规则时恢复当前战斗开始前快照重试。不得残留失败战的临时血量/消耗，也不重复补给或已结算节点奖励。重试前须检查可用快照及加载能力，加载失败留在可操作页并显示真实原因。
3. 返回按工程既有失败返回目标执行。若原流程不允许安全返回，禁用并说明，不能把失败结果误作胜利回图或跳过当前节点。本包按钮表示设计目标，具体支持能力须在工程核实。
4. 连点重试/返回仅提交一次，加载中禁用操作；失败恢复可重试。Esc和其他返回输入遵循同一失败流程，不绕过业务检查。

## 结果与持久化

奖励归属只保留一方：沿用战斗模块或外层事件既有权威提交点。显示「胜利」和奖励前必须拿到最终真实结果；UI不根据敌人动画或面板打开猜胜负。通过战斗/事件唯一标识防重，奖励、HP/消耗、节点完成及任务变化保持一致。UI生命周期和存档恢复不能重复应用结果。

存档沿现有安全点：地图事件在整条事件结束并回图稳定后保存；地下城按节点安全点保存。不因打开结算页或鼠标悬停新增保存。写盘失败沿现有提示/重试机制，不能再次发奖。此包不新增战斗中存读或未完成事务持久化系统。

## 接线顺序与验收

先核对现有结果与失败链路 → 导入独立素材并组装两页 → 绑定真实奖励列表与Tooltip → 接确定/返回/重试 → 完成以下针对性检查。

| 检查 | 通过条件 |
| --- | --- |
| 胜利视觉 | 红金胜利，无侠印；暖纸、四列小格、底部确定，三张定稿可对照 |
| 奖励0/1/3/8/12项 | 顺序稳定，不拉伸，溢出可滚动，零奖励无假条目 |
| 心得 | 显示物品数量，结算后人物经验不因展示自动增加；真实物品可按原系统使用 |
| Hover | 高亮唯一，说明与条目一致，边缘翻转，离开/滚动/关闭清理，无操作按钮 |
| 真实结果 | 数量、HP、任务和节点一致；重复回调/重开/读档不重复领取 |
| 失败 | 不推进、不发胜利奖；重试按原规则恢复；返回与重试互斥 |
| 错误路径 | 加载/结算失败有原因和可用恢复入口，不留永久输入锁 |
| 分辨率 | 1920×1080、1280×720及工程支持宽高比可读、无裁切，长名称/大数量不溢出 |
