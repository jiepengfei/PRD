# 美术资源与组装说明

## 导入

把 Assets/WuxiaBattleSettlementUI 复制到工程 Assets 下或按工程规范映射。若工程已有同名同源资源，引用原GUID，避免重复导入。运行菜单 Tools/Wuxia/Battle Settlement/Apply Art Import Settings，选择本包manifest.json。导入工具仅设置美术参数，不建Prefab、不接业务。

PNG 使用 Sprite/UI、Single、Full Rect、sRGB、Alpha Is Transparency、Bilinear、Clamp、无MipMaps、无压缩。PPU默认100，最终服从工程规范。面板、按钮、格底按manifest设置9-slice；图标、标题、插画用Simple、Preserve Aspect。背景尺寸上限按原始图设定。

## 组装

1. 全屏背景优先复用当前战斗背景，叠少量暗色遮罩；不要在真实场景上重复铺两张背景。
2. 主面板见Data/layout.json，参考画布1672×941，顶左原点。整体缩放至安全区，面板可见范围约608×878。主面板使用panel_paper_textured.png的Simple图，按alphaBounds将纸面可见范围对齐，透明留白不计入面板尺寸；Tooltip使用panel_paper.png九宫格。Tooltip单独浮层，不被面板Mask裁掉。
3. 标题透明PNG包含画布留白，manifest的alphaBounds为可见范围，按可见主体对齐。胜利目标可见范围约420×132；失败同级。禁止把素材整张画布压成420×132导致书法变窄。标题是固定艺术字，其他中文使用工程现有中文字体动态渲染。
4. 物品格96×96，间距29×33，四列；数量右下。复用格底后叠朱红Outline或独立边框控件实现hover，避免把整张图标染红。已有格底边色可用Image颜色微调，图标Image保持白色。
5. 暖纸主面板为无文字透明独立图，按钮、格底和Tooltip底为复用控件素材，细节与生成参考有差异，接入时以Reference校准整体色温和边线；不能整图覆盖这些差异。主按钮状态配齐normal/hover/pressed/disabled，文字独立。
6. 获得道具两侧细线可复用divider并由UI补小菱形端点；失败插画与说明分别显示。Tooltip同用纸底，文字从物品配置绑定。
7. 图中八项仅演示物品排列。包内铜钱、止血散、心得是可映射图标；SampleItems仅示意，正式物品优先用工程已有图标。布匹、竹筒等参考物不能据此新增掉落，缺图用既有缺省图而非截图裁片。

## 资源来源与限制

独立透明标题、失败插画、无文字暖纸主面板、心得和药瓶由内置imagegen参照已确认图重新生成。通用Tooltip纸面/按钮/分隔线复用UI/DetailCardArt/v01；物品格、铜钱和示意图标复用Delivery/Inventory/v01；背景复用Delivery/BattlePage/v02。具体文件来源、SHA256、尺寸、透明范围、9-slice在manifest中。

Reference整图含文字和示意数值，仅供验收；不得当运行时面板。没有打包商业游戏参考截图、字体、第三方图或Unity .meta。不可直接覆盖目标工程已有GUID。标题是艺术字，可用于固定文案；切换语言需准备对应标题或改为字体控件。
