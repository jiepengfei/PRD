# 补给 CG 与离村送别 CG 接入需求

日期：2026-11-06 · 版本：v0.2 · 状态：按用户纠正后的范围整理，未上传或通知实施。

本稿取代《临时 CG 与对白接入方案》作为当前实施范围。**本轮只接两段：村民补给 CG、离村送别 CG，用于串通正常通关线路。** 不做支线、传剑回忆、烧抢或超时后果，也不把这些内容安排为本次后续阶段。

## 1. 正常线路

**小兵二胜利 → 补给 CG 与对白 → 一次性回血 → 首领战 → 主线完成 → 村长对话 → 出口开放 → 确认离村 → 送别 CG 与对白 → Demo 结束。**

此前已经接入的战斗、主线、村长和出口保持原逻辑；先核对实际实现，再补两段表现及必要结果接线，不重做这些系统。结束仅需明确显示“Demo 结束／未完待续”，复用已有 UI 提供返回标题，不扩展新的结算系统。

## 3. 补给接入

- 在正式首领地下城现有补给节点，使用补给图配两句对白，替换纯对白占位，不另加第二个补给节点。
- 小兵二胜利后才可进入；点击后通过现有通用 CG/对话组件展示，图片按原比例显示，不新增配音、立绘或动画需求。
- 正常结束或明确跳过后，走原补给节点的统一成功结果，治疗至当前有效生命上限一次，再开放首领战。
- 保留原节点 ID、领取状态和防重逻辑。重复回调、暂离重进或首领失败重试不再次领取；接图不能导致额外回血或重置进度。
- 异常关闭和资源失败不提前提交节点完成，按现有机制恢复/重试。

## 4. 送别接入

- 使用 Step 06 已开放的同一出口，村长战后对话未完成时仍不能离村。
- 接通出口离村操作，提示“离开村庄将结束本次 Demo”，取消留在地图，确认后播放送别图与三句对白；取消后不能因站在出口格每帧重复弹窗。
- 正常结束或明确跳过都只提交一次章节完成，清理流程输入锁并进入明确的 Demo 结束状态，不加载不存在的下一章。
- 不再次结算主线奖励，不修改已经完成的山贼主线。结束状态屏蔽地图操作，返回标题使用原有入口。
- 接现有存档保留章节结果，不擅自覆盖所有手动槽位。存档最终验收由用户负责，实施方仍完成必要接线与自检。

## 5. 完成标准

1. 小兵二结束后能观看/跳过补给图与对白，回血一次并继续首领战。
2. 现有首领胜利、村长对话及出口开放仍能正常衔接。
3. 离村确认可取消；确认后显示送别图与对白，观看完或跳过均进入 Demo 结束状态并可返回标题。
4. 没有重复治疗、领奖、剧情多开、输入穿透、画面拉伸或异常退出后卡死。
5. 提供两段实际运行截图或短视频，以及改动、配置引用与未解决项。只交付图片不算接入完成。

完成这条正常通关线路后停止；本次不接其他 CG 或支线。
